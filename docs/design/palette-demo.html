SIFT palette — dark fintech × antique metal

Dark mode by default. Antique (aged, desaturated) bronze / silver / gold / platinum for card tiers, oxidized-teal + brass accents for the art-nouveau undertone, one reserved green for “survived the gauntlet”. All text pairs on this page meet WCAG AA (≥4.5:1).

Typography — four OFL faces, one per voice

CINZEL — displayengraved inscription caps · wordmarks, tier bands, rank letters, h1/h2 · wght 400–900 variable · OFL
Spectral — card copy & prosescreen-first serif · 300/400/600 + italic · OFL
IBM Plex Sans — UI bodyfintech dashboard neutral · 400/500/600 · OFL
IBM Plex Mono 0123456789 +4.02% |z|≥4.0numbers, tickers, hex codes, stage pills · tabular-nums · OFL

Fallbacks: Cinzel → Times New Roman; Spectral → Georgia; Plex Sans → system-ui; Plex Mono → ui-monospace. All four load from Google Fonts (css2 API, display=swap) and degrade gracefully offline.
